# Work Time Tracker

A small installable Android-friendly Progressive Web App (PWA).

## Features
- Record arrival/departure with one tap using the current device time.
- Enter or edit dates and times manually.
- Daily duration calculation (including overnight shifts).
- Weekly/monthly/all-time statistics and average.
- Edit/delete history and export CSV.
- Offline app shell; records are stored locally in this browser on this device.

## Install on Android
1. Publish the contents of this folder to a static HTTPS host (for example GitHub Pages or Netlify).
2. Open the published HTTPS address in Chrome on Android.
3. Open Chrome's menu (⋮) and choose **Install app** or **Add to Home screen**.
4. Launch it from your home screen.

## Important
- Your records are stored in this browser's local storage. They are not synced to another phone or browser.
- Clearing Chrome site data can erase the records. Export CSV regularly as a backup.
- If you change phones, export the CSV before switching; CSV import is not included in this first version.
